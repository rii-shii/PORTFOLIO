Technova Solutions — Sales & Performance Dashboard

An interactive Power BI dashboard designed to analyze and visualize sales performance for Technova Solutions. 
The dashboard provides insights into total sales, profit, orders, quantity, discounts, product performance, regional sales, customer segments, categories, payment methods, and sales trends over time. 
It transforms raw sales data into clear and interactive visualizations to support data-driven business analysis and decision-making.
